# Supermarket sales queries (PostgreSQL)

- **`queries-postgres.sql`** — analysis queries (revenue by branch/city, product line, payments, monthly trend, duplicates).
- **`queries.sql`** — short samples and quick references.
- **`filter-product-line.sql`** — example `ILIKE` filter on `product_line`.

Table name matches **`TABLE_NAME`** in `db/.env` (default **`supermarket_sales`**).
